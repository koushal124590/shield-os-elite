## 📋 About

**Antigravity** is the core OS-level protocol powering the SCP ecosystem. Built on **SHIELD OS Elite**, it delivers a unified desktop experience with native installers, a branded portfolio site, Android Capacitor integration, and robust Firebase backend services.

> 🛡️ *Your desktop. Elevated.*

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-org/antigravity.git

# Navigate to the project
cd antigravity

# Install dependencies
npm install

# Start the application
npm start

# Build Windows executable
npm run build:win

# Build standalone EXE installer
npm run build:exe
```

<br>

## 📁 Project Structure

```
antigravity/
├── 📄 app.js                    # Main application entry
├── 📄 build-installer.js        # Windows installer builder
├── 📄 capacitor.config.json     # Capacitor (Android) config
├── 📂 android/                  # Android native project
├── 📂 app website/              # Portfolio & landing page
├── 📂 assets/                   # Images, logos & branding
│   └── 3d-logo-spinning.gif     # SCP animated logo
├── 📂 bin/                      # Compiled binaries
├── 📂 public_branding/          # Public branding assets
├── 📂 releases/                 # Build releases & installers
├── 📂 www/                      # Web build output
└── 📂 archive/                  # Previous version backups
```
